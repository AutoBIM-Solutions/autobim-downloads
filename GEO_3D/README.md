# AutoBIM-GEO_3D

Geometria rodoviária para Civil 3D 2023–2027. O instalador copia o bundle `AutoBIM.Geo3D` para os plugins do Civil 3D.

| Campo | Valor |
|---|---|
| Repositório | https://github.com/AutoBIM-Solutions/AutoBIM-GEO_3D |
| Versão de registro | 0.7.0 (`PackageContents.xml` AppVersion) |
| Arquivo | `AutoBIM-GEO_3D_Instalador_0.7.0.exe` |
| Tag da release | `GEO_3D-v0.7.0` |

O `.exe` fica na release, não nesta pasta. A constituição do produto obriga a IA a publicar esta release no commit que muda o `AppVersion`.
