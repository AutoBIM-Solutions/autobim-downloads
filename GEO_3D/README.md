# AutoBIM-GEO_3D

Geometria rodoviária para Civil 3D 2023–2027. O instalador copia o bundle `AutoBIM.Geo3D` para os plugins do Civil 3D.

| Campo | Valor |
|---|---|
| Repositório | https://github.com/AutoBIM-Solutions/AutoBIM-GEO_3D |
| Versão no instalador | 0.6.0 (`deploy/InstaladorGUI/InstaladorGEO3D.csproj`) |
| Arquivo | `AutoBIM-GEO_3D_Instalador_0.6.0.exe` |
| Tag da release | `GEO_3D-v0.6.0` |

O `.exe` fica na release, não nesta pasta. Esta pasta só descreve a versão.

Download: https://github.com/AutoBIM-Solutions/autobim-downloads/releases/download/GEO_3D-v0.6.0/AutoBIM-GEO_3D_Instalador_0.6.0.exe
