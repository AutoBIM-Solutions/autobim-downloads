# AutoBIM-DRE_3D

Drenagem 3D (`DrenagemQTD`) para Civil 3D 2023–2027. O instalador copia o bundle `DrenagemQTD` para os plugins do Civil 3D.

| Campo | Valor |
|---|---|
| Repositório | https://github.com/AutoBIM-Solutions/AutoBIM-DRE_3D |
| Versão de registro | 1.19.0 (`PackageContents.xml` AppVersion) |
| Arquivo | `AutoBIM-DRE_3D_Instalador_1.19.0.exe` |
| Tag da release | `DRE_3D-v1.19.0` |
| Release | https://github.com/AutoBIM-Solutions/autobim-downloads/releases/tag/DRE_3D-v1.19.0 |
| Commit de origem | AutoBIM-Solutions/AutoBIM-DRE_3D@cd7401f (branch `feature/teste-gratis`) |

O que o instalador coloca no Civil 3D: `%APPDATA%\Autodesk\ApplicationPlugins\DrenagemQTD.bundle`, com as DLLs para 2023–2024 (R24), 2025–2026 (R25) e 2027 (R26).

1.19.0: painel Início com Login e Ajuda menores e o selo verde da licença (Conta ativa / Teste: restam N dias / Adquira agora / Faça login para usar), que abre a página do Drenagem 3D no site.

URL para a plataforma (`installer_url`):

`https://github.com/AutoBIM-Solutions/autobim-downloads/releases/download/DRE_3D-v1.19.0/AutoBIM-DRE_3D_Instalador_1.19.0.exe`

O `.exe` fica na release, não nesta pasta. A constituição do produto obriga a IA a publicar esta release no commit que muda o `AppVersion`.
