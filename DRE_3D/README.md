# AutoBIM-DRE_3D

Drenagem 3D (`DrenagemQTD`) para Civil 3D 2023–2027. O instalador copia o bundle `DrenagemQTD` para os plugins do Civil 3D.

| Campo | Valor |
|---|---|
| Repositório | https://github.com/AutoBIM-Solutions/AutoBIM-DRE_3D |
| Versão de registro | 1.18.0 (`PackageContents.xml` AppVersion) |
| Arquivo | `AutoBIM-DRE_3D_Instalador_1.18.0.exe` |
| Tag da release | `DRE_3D-v1.18.0` |

O `.exe` fica na release, não nesta pasta. A constituição do produto obriga a IA a publicar esta release no commit que muda o `AppVersion`.
