# AutoBIM-DRE_3D

Drenagem 3D (`DrenagemQTD`) para Civil 3D 2023–2027. O instalador copia o bundle `DrenagemQTD` para os plugins do Civil 3D. O catálogo Excel acompanha o pacote.

| Campo | Valor |
|---|---|
| Repositório | https://github.com/AutoBIM-Solutions/AutoBIM-DRE_3D |
| Versão no projeto do instalador | 1.0.0 (`deploy/InstaladorGUI/InstaladorDRE3D.csproj`) |
| Plugin (README do produto) | linha 1.15 |
| Arquivo | `AutoBIM-DRE_3D_Instalador_<versão>.exe` |
| Tag da release | `DRE_3D-v<versão>` |

O `.exe` fica na release, não nesta pasta. A versão do `.csproj` do instalador ainda está em 1.0.0; confirme o número no `PackageContents.xml` antes de publicar.
